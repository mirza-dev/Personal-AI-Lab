## Product

Personal AI Lab is a learning-driven project that grows from a small Python program into a production-oriented platform for:

- API and local language models
- model comparison and benchmarking
- a custom Turkish evaluation benchmark
- fine-tuning experiments
- RAG over personal documents
- tools and agent workflows
- FastAPI and PostgreSQL
- Docker, CI/CD and observability
- a personal assistant built on top of these components

## Learning approach

The project follows this loop:

```text
Learn → Build → Test → Measure → Document → Commit
```

The roadmap is checkpoint-based rather than day-based.

Some days may include more study than others. Progress is determined by completed learning objectives and working product output, not by a fixed daily schedule.
